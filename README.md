# 长三角地铁 2D 动态线路图（上海 / 苏州 / 杭州）

按**官方时刻表**推演的城市轨道动态线路图：给定任意时刻，图上显示每条线路、
**每一个方向上正在运行的每一列车**——一条线路上同时显示多列车，因此可以直接看出
**发车间隔**与列车的分布。

支持三个数据集，页面右上角一键切换：

| 城市 | 线路 | 交路 | 车站 | 特色 |
|---|---|---|---|---|
| 上海 | 21 条 | 24 个 | 418 座 | 含磁浮线、市域机场线；4 号线环线；5/10/11 号线支线 |
| 苏州 | 9 条 | 9 个 | 236 座 | 含 3/11 号线贯通段；另有**有轨电车**数据集 |
| 苏州高新区有轨电车 | 2 条 | 2 个 | 29 座 | 高新有轨电车 1/2 号线 |
| 杭州 | 12 条 | 14 个 | 260 座 | 含 3/6 号线两支交路 |

## 在线访问

**<https://sunwebgo.github.io/shmetro-live/>**

打开后：点右上角切换城市；把「日期类型」切到 **周一~周四**、时间轴拖到 **08:00** 看早高峰；

## 功能

| 功能 | 说明 |
|---|---|
| 三城切换 | 上海 / 苏州 / 苏州有轨电车 / 杭州，切换后自动重新适配视野 |
| 全网动态运行 | 逐列车按发车时刻表在图上运行，全网高峰同时在线上限约 750 列（上海） |
| 双向显示 | 每条线路按上/下行分别生成列车；车头白色三角指示行车方向 |
| 间隔可视化 | 同一条线路上多列车同时可见，高峰时列车间距明显变密 |
| 时间轴 | 拖动滑块到任意时刻；支持 1×／60×／300×／900× 推演与暂停 |
| 实时模式 | 「回到此刻」跟随真实时间（Asia/Shanghai） |
| 日期类型 | 自动／周一~周四／周五／周六／周日，套用官方不同班表 |
| 线路详情 | 侧栏列出每条线当前的实际发车间隔、两方向在线列车数、首末班车时刻 |
| 车站到站 | 点击任意车站，显示该站各线路两方向的下一班列车、到站时刻与倒计时 |
| 地图交互 | 拖拽平移、滚轮缩放（围绕光标）、点击线路高亮、图例点击显隐线路 |

## 数据来源

三城共用**高德地图**的线路走向与站点经纬度（`map.amap.com/service/subway?srhdata={adcode}_drw_{city}.json`），
线路色以各地官方色值为准。首末班车与行车间隔来源如下：

| 城市 | 首末班车 | 行车间隔 |
|---|---|---|
| 上海 | 上海地铁官网接口 `func=fltime&line=N`（逐站、逐方向） | 官网「首末班车时刻表」页的**列车间隔表**（工作日/周五/双休日/延时运营，分时段分区段） |
| 苏州 | 苏州轨道交通官网时刻表接口（逐站、逐方向，分「周一至周四」「周五至周日」两套） | DTO 内 `guideDescZh` 的官方描述文本（如「工作日早高峰行车间隔约2-4分钟」），取区间中值 |
| 苏州电车 | — | 参考公开信息建模 |
| 杭州 | 杭州地铁官网接口 `POST /api/operation/all` 的 `subwaySiteDetail`（逐站、逐方向） | 官网未提供，采用参考公开信息的典型值 |

抓取到的原始响应保存在 `data/raw/`（各城市 AMap JSON、上海 `official/fltime_*.txt` 与 `hcskb_0.html`、
苏州 `sz_dto/*.json`、杭州 `hz_all.json`、OSM 电车关系 `osm_suzhou_tram_geom.json`）。

## 推演口径

1. **首班车**：取官方该站该方向的首班车时刻；**末班车**取官方末班车时刻。
   上海周五/周六按官方 `last_time_desc` 的分钟增量顺延（如 1 号线 +88 分钟）；
   苏州按「周五至周日」班表切换（`fwd.alt`）。
2. **发车间隔**：上海/苏州按官方间隔数据；表中「其余时段 x 分～y 分」按线性过渡处理
   （首班车后由慢变快、末班车前由快变慢）；周五/周六 22:30 后切换到延时运营间隔（上海）。
3. **站间运行时分**：若官方逐站首班车时刻单调可用，则用其差分推导（苏州 1/7/8 号线即如此）；
   否则退回 `停车 35 秒 + 站间里程 / 线路旅行速度` 建模。上海因存在多点首班车，全部采用模型值。
   默认旅行速度 48 km/h，高速线单独设定（16 号线 72、磁浮 200、市域机场线 100、19 号线 80、电车 22）。
4. **多交路**：5/10/11 号线（上海）、3/6 号线（杭州）的各支线作为独立交路运行，共线段列车叠加后，
   共线区间的实际间隔与官方一致。
5. **4 号线**（上海）为环线，按内圈 / 外圈两个方向分别生成列车。
6. **苏州有轨电车**站序由 OSM 线路几何拼接后投影确定（`tools/order_tram_stops.js`），非官方数据。

### 已知简化

- 延时运营期间官方只延长**部分区段**（如 7 号线祁华路～花木路），本图按该线路的延时幅度顺延全线末班车，未做区段截断。
- 未模拟 2 号线东延伸、16 号线大站车/直达车等特殊交路，也未模拟区间车提前折返。
- 杭州行车间隔为典型值；官网接口当前返回周末时刻表，工作日与之差异通常在数分钟内。
- 绍兴 1 号线（绍兴市线路）、杭海城际（城际铁路）未纳入杭州地铁统计。
- 磁浮线与有轨电车班次为参考公开信息估算。
- 列车位置是按时刻表推演的**示意位置**，不是真实车辆定位数据。

## 目录结构

```
shmetro-live/
├─ index.html                 入口（直接双击打开）
├─ css/style.css
├─ js/sim.js                  仿真内核：多城市切换、发车表生成、时刻→位置、到站推算
├─ js/app.js                  Canvas 渲染、交互、城市切换、面板
├─ data/metro-data.js         三城前端数据（由构建脚本生成，约 83 KB）
├─ data/preview_*.png         各城市静态预览图
├─ data/raw/                  抓取到的官方 / 高德 / OSM 原始数据
└─ tools/
   ├─ build_data.py           生成 data/metro-data.js（含三城解析与行车间隔表）
   ├─ order_tram_stops.js     重建有轨电车折线并确定站序
   ├─ test_sim.js             仿真内核无头校验（三城）
   ├─ test_ui.js              前端脚本无头校验（Node + DOM 桩，含城市切换）
   ├─ snapshot.js             导出指定城市/时刻的绘制数据
   └─ render_png.py           把快照渲染成 PNG
```

## 重新构建 / 校验

```powershell
$py   = "<python>"        # 标准库即可
$node = "<node>"

# 0) 可选: 重新定序有轨电车(改过 OSM 原始数据时)
& $node tools/order_tram_stops.js

# 1) 由原始数据重新生成三城前端数据
& $py   tools/build_data.py          # -> data/metro-data.js + data/build-report.txt

# 2) 仿真内核校验（三城结构、间隔、发车表、苏州双班表、位置、到站）
& $node tools/test_sim.js

# 3) 前端脚本校验（渲染、面板、交互、城市切换、全时段绘制）
& $node tools/test_ui.js

# 4) 生成静态预览图
& $node tools/snapshot.js suzhou mon_thu 1 08:00 data/snap.json 1600 1000
& $py   tools/render_png.py data/snap.json data/preview_suzhou_0800.png
```

`tools/build_data.py` 中的 `HEADWAY_SH` 是上海官方间隔表的人工整理结果（每条附官方原文），
可按需修改后重新构建。
